이 조회에는 GitHub 앱의 저장소 Administration: Read-only 권한이 필요합니다. 조직 Members 읽기 권한과는 다릅니다. ProjectManager의 기존 앱 설정 가이드는 Administration 권한을 요청하지 않으므로, 이 설정을 따랐다면 조회가 제한될 수 있습니다.

  1. 앱 관리자에게 앱 설치 여부, 대상 저장소 선택 범위, 현재 권한과 설치의 변경 승인 상태를 확인해 달라고 요청하세요.
  2. 권한을 유지하려면 GitHub 저장소의 접근 관리 화면에서 팀을 확인하세요. 해당 화면은 저장소 관리자 권한이 필요할 수 있습니다.
  3. 웹에서 팀 목록이 필요하다면 앱 관리자가 Administration 읽기 권한 추가를 검토하고, 설치 관리자가 변경을 승인한 뒤 다시 조회하세요. 쓰기 권한은 이 조회에 필요하지 않습니다.
  4. HTTP 401·403·404는 권한·인증·저장소 범위 등 여러 원인이 있을 수 있습니다. 네트워크 오류는 운영자에게 연결 상태 확인을 요청하세요.
