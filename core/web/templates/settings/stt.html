내 PC 전사 서버

{# COPY:settings_stt_title #}

내 PC에서 설치·연결 명령을 실행하고 표시된 코드를 {{ link_url }}에 입력해 주세요. PC가 연결되어 있는 동안 접근할 수 있는 회의록의 녹음을 이 PC로 전사할 수 있습니다. 포트를 열 필요가 없습니다.

{# COPY:settings_stt_intro #}
Windows PowerShell

{{ install_ps1 }}

내 PC의 PowerShell에 붙여 넣어 실행해 주세요. Docker가 있으면 Docker로, 없으면 uv로 설치합니다. Codex는 uv로 설치한 udally-link에서만 사용할 수 있습니다. 관리자 권한은 필요하지 않습니다.

{# COPY:install_windows_help #}
macOS · Linux 터미널

{{ install_sh }}

내 PC의 터미널에 붙여 넣어 실행해 주세요. 다시 실행하면 최신 버전으로 업데이트합니다.

{# COPY:install_unix_help #}
고급 · 제거

설치 스크립트는 실행 전에 열어 볼 수 있습니다: install.ps1 · install.sh. 이미 udally-link를 설치했다면 udally-link connect로 연결합니다.

{# COPY:install_advanced_help #}

제거(Windows): {{ uninstall_ps1 }}

제거(macOS·Linux): {{ uninstall_sh }}

제거하면 이 화면의 PC 연결도 끊깁니다. 받은 모델 파일은 남으며 삭제 방법은 제거 명령이 안내합니다.
