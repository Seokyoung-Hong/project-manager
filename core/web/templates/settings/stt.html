내 PC 전사 서버

{# COPY:settings_stt_title #}

PC에서 명령 한 줄을 실행하고 화면에 뜬 코드를 {{ link_url }}에 입력하면 연결됩니다. PC가 켜져 있는 동안 내가 볼 수 있는 회의록의 녹음을 그 PC로 전사합니다. 포트를 열 필요가 없습니다.

{# COPY:settings_stt_intro #}
Windows PowerShell

{{ install_ps1 }}

PowerShell에 붙여 넣어 실행해 주세요. Docker가 있으면 Docker로, 없으면 uv로 설치합니다. 관리자 권한은 필요하지 않습니다.

{# COPY:install_windows_help #}
macOS · Linux 터미널

{{ install_sh }}

터미널에 붙여 넣어 실행해 주세요. 다시 실행하면 최신 판으로 업데이트합니다.

{# COPY:install_unix_help #}
고급 · 제거

설치 스크립트는 실행 전에 열어 볼 수 있습니다: install.ps1 · install.sh. 이미 udally-link를 설치했다면 udally-link connect로 연결합니다.

{# COPY:install_advanced_help #}

제거(Windows): {{ uninstall_ps1 }}

제거(macOS·Linux): {{ uninstall_sh }}

제거하면 이 화면의 연결도 함께 끊깁니다. 받은 모델 파일은 남으며, 지우는 방법은 제거 명령이 알려 줍니다.
