셸이 있는 Claude Code에서는 스킬이 가장 가볍습니다. claude.ai 웹·모바일처럼 셸이 없는 곳은 OAuth 커넥터로 붙습니다.

클라이언트설정
Claude Code
스킬 · 이 기기만		 저장소의 skills/ 폴더(pm, pm-*)를 ~/.claude/skills/에 복사하고 pm.py login으로 로그인합니다(브라우저에서 허용 — 토큰을 손으로 옮기지 않습니다). /pm-start, /pm-new 같은 명령이 생깁니다. 자세한 방법은 skills/README.md를 보세요.
Claude 앱 / claude.ai
OAuth		 설정 → 커넥터 → 커스텀 커넥터 추가 → URL {{ mcp_url }}/mcp
'연결'을 누르면 이 사이트의 로그인·허용 화면이 뜹니다. 허용하면 토큰이 자동으로 발급돼 API 토큰 목록에 추가됩니다 — 위에서 따로 발급하지 않아도 됩니다.
Claude Code
MCP · 헤더		 claude mcp add --transport http udally {{ mcp_url }}/mcp --header "Authorization: Bearer <TOKEN>"
Codex CLI
헤더		 ~/.codex/config.toml에 [mcp_servers.udally] url = "{{ mcp_url }}/mcp" bearer_token_env_var = "UDALLY_TOKEN" 추가, 환경 변수 UDALLY_TOKEN=<TOKEN>
그 밖의 클라이언트
개인 비밀 URL		 OAuth도 헤더도 못 넣는 곳이면 URL에 토큰을 넣습니다: {{ mcp_url }}/u/<TOKEN>/mcp — 클라이언트의 별도 인증 설정은 필요하지 않습니다. URL에 포함된 토큰으로 인증합니다.
