AI 도구 연결하기

연결할 AI 도구를 선택해 주세요. claude.ai에서는 주소를 등록하고 인증하면 토큰이 발급됩니다.

Claude 앱 / claude.ai 추천 · 주소만 복사

설정 → 커넥터 → 커스텀 커넥터 추가 → URL {{ mcp_url }}/mcp

'연결'을 누르면 이 사이트의 로그인·허용 화면이 뜹니다. 허용하면 토큰이 자동으로 발급돼 아래 토큰 목록에 추가됩니다. 따로 발급하지 않아도 됩니다.

Claude Code 스킬 · 이 기기만

저장소의 skills/ 폴더(pm, pm-*)를 ~/.claude/skills/에 복사하고 pm.py login으로 로그인합니다(브라우저에서 허용 — 토큰을 손으로 옮기지 않습니다). /pm-start, /pm-new 같은 명령이 생깁니다. 자세한 방법은 skills/README.md를 확인해 주세요.

Claude Code MCP · 헤더

claude mcp add --transport http udally {{ mcp_url }}/mcp --header "Authorization: Bearer <TOKEN>"

<TOKEN>은 아래 ‘직접 발급’에서 만든 AI용 토큰입니다.

Codex CLI 헤더

~/.codex/config.toml에 [mcp_servers.udally] url = "{{ mcp_url }}/mcp" bearer_token_env_var = "UDALLY_TOKEN" 추가, 환경 변수 UDALLY_TOKEN=<TOKEN>

<TOKEN>은 아래 ‘직접 발급’에서 만든 AI용 토큰입니다.

그 밖의 클라이언트 개인 비밀 URL

OAuth도 헤더도 못 넣는 곳이면 URL에 토큰을 넣습니다: {{ mcp_url }}/u/<TOKEN>/mcp — 클라이언트의 별도 인증 설정은 필요하지 않습니다. URL에 포함된 토큰으로 인증합니다.

개인 비밀 URL은 비밀번호와 같습니다. 주소창과 프록시 기록에 남으니, 넣을 곳이 있으면 헤더나 OAuth를 사용해 주세요. 유출되면 이 화면에서 폐기해 주세요.
