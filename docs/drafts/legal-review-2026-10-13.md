이 목록은 배포 전 확인을 위한 편집 주석이며 사용자 고지의 법적 충분성을 확정한 내용이 아닙니다.

- 조직과 개인 AI마다 실제 운영자 법인명·연락처·처리 및 재위탁 국가·구체적 보유 기간을 확정하고 관련 정보주체가 전송 전에 확인하는 안내 경로를 마련해야 합니다. ‘조직이 지정한 서버’만으로 법정 고지 항목이 충분한지는 확인되지 않았습니다. 현재 주소·모델·키 입력 화면은 이 모든 정보를 수집·고지하는 화면이 아닙니다.
- 다른 구성원의 표시 이름·업무 본문, GitHub 이슈의 비회원 개인정보, 조직 밖 개인 AI의 처리·목적 외 이용·재위탁을 검토해야 합니다. 로그인한 이용자의 동의가 다른 정보주체의 동의를 대신하지 않습니다. 조직·등록 이용자의 책임 명시가 쿼넥트의 의무를 면제하지 않습니다.

## Codex 구독·내 PC 경로 추가 검토(2026-10-13)

- 이용자 OpenAI 구독 계정을 통한 업무 자료 및 PC 파일 내용의 전송이 처리위탁·제3자 제공 중 어디에 해당하는지, 국외 이전 근거와 별도 동의 필요 여부, 다른 구성원·비회원 정보에 대한 고지·동의 주체를 검토해야 합니다. 일반 처리방침·약관 재동의만으로 충분하다고 단정할 수 없습니다. 검토 기준은 [개인정보 보호법 제28조의8](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1034292881)입니다.
- 공개본은 이전받는 자·연락처를 기존 OpenAI 표와 같은 OpenAI, L.L.C.·https://privacy.openai.com/로 기재했습니다. 실제 이용자 계정의 계약 법인, 미국 외 처리·보관·재위탁 국가와 구체적인 보유·삭제·모델 개선 이용 조건을 확정하고 전송 전에 확인할 안내 경로를 마련해야 합니다. 구독 경로에 서비스의 전사·요약 API 보관 기준을 그대로 적용해서는 안 됩니다. [Codex 인증 공식 문서](https://developers.openai.com/codex/auth)의 구독 계정·API 키 구분을 참고하며, 계정별 계약·정책의 법적 적용은 별도 확인이 필요합니다.
- 읽기 전용이 PC 파일 읽기를 제한하지 않는 범위, 프롬프트 주입으로 PC 파일 내용이 모델 요청·답변에 실리는 위험, 도구의 네트워크 차단과 OpenAI 모델 통신의 구분을 실제 udally-link 실행 설정과 대조해야 합니다. [Codex 보안 공식 문서](https://developers.openai.com/codex/security)를 참고하되 제품의 보호 조치가 모든 위험을 제거한다고 고지해서는 안 됩니다. 이용자 주의·책임 문구가 쿼넥트의 법적 의무를 면제하거나 과도하게 책임을 전가하지 않는지도 검토해야 합니다.
- 결과의 요청자 본인 열람, 적용 전 업무 본문·태스크 미저장과 AI 작업 기록 7일 보관이 서로 구분되는지 실제 접근 권한·로그·백업을 확인해야 합니다. 현재 PC 결과 수신 코드는 결과를 AI 작업 기록에 저장합니다(core/assist/pc.py:178, core/assist/pc.py:217). 따라서 공개본의 적용 전 미저장은 업무 본문·태스크에 한정하며, 결과 자체가 전혀 저장되지 않는다고 안내해서는 안 됩니다. 두 공개 문서의 시행일은 2026-10-13, 판 번호는 처리방침 v3·약관 v2로 유지합니다.

## 계정 실명·조직 표시 이름 추가 검토 — 처리방침 v5·약관 v4(2026-10-13 작성)

이번 개정은 core/web/content/privacy.md(v5)·terms.md(v4)에 반영하였으며 시행일은 두 문서 모두 “(배포일)”로 남겼습니다. 아래 사항은 배포 전 검토 대상이며 공개 문구만으로 처리의 적법성이나 동의의 충분성을 확정하지 않습니다.

- **실명 필수 수집과 이용 제한:** 실명이 계정당 하나의 가입 필수 항목이 되고 미입력 기존 이용자도 다음 로그인 시 입력해야 이용할 수 있습니다. 조직에 가입하지 않은 이용자까지 포함한 필수 수집의 필요성·최소성, 계약 이행 근거의 적용 범위와 실명 입력 거부 시 전체 이용 제한의 적합성을 확인해야 합니다. 실명 정확성에 관한 이용자 의무는 본인 확인이나 실명 인증을 제공한다는 뜻이 아닙니다. 근거: docs/IMPL-PLAN-13-realname-org-nickname.md §5·§10, privacy.md 제1조·제2조, terms.md 제4조, [개인정보 보호법 제16조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0016&lsiSeq=283839&urlMode=lsScJoRltInfoR).
- **모든 소속 조직 관리자 열람:** “실명으로 표시”가 꺼진 조직도 관리자가 구성원 계정 실명을 열람합니다. 서비스가 직접 수집한 실명을 조직에 열람시키는 처리의 제3자 제공·위탁 등 법적 성격, 적법한 근거와 필요한 제공 고지·동의를 판단해야 합니다. 조직 가입·초대 수락 안내만으로 별도 동의를 갈음한다고 단정해서는 안 됩니다. 기존에 실명을 받지 않거나 선택으로 받던 조직의 관리자에게 열람을 확대하는 경우의 사전 고지와 정보주체 권리 행사 절차도 확인해야 합니다. 근거: 계획 §6.2·§10·§13, privacy.md 제4조, terms.md 제6조, [개인정보 보호법 제17조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334879).
- **구성원 전체 공개와 외부 전송:** 설정을 켜면 해당 조직 구성원 전원과 조직 맥락의 AI·MCP·API·Discord·전사 용어집에 실명이 포함됩니다. 관리자 설정 변경만으로 다른 구성원의 실명 공개·전송 근거가 충족되는지, 수신자·목적·처리 국가·보유 기간 고지와 별도 동의 필요 여부, 공개·이전 거부 및 조직 탈퇴 선택의 실효성을 검토해야 합니다. 조직 AI뿐 아니라 개인 AI·내 PC·계정 연결 경로도 대상입니다. GitHub 저장소 글의 작성자 이름은 계정 표시 이름이지만 Copilot 업무 맥락이나 이용자가 작성한 본문까지 실명 전송이 차단되는 것은 아닙니다. 근거: 계획 §4.1·§4.3·§10, privacy.md 제4조·제6조, terms.md 제6조·제9조, [개인정보 보호법 제28조의8](https://www.law.go.kr/법령/개인정보보호법/제28조의8).
- **기존 값 이전과 충돌 후보:** 기존 조직별 실명의 계정 이전으로 다른 소속 조직의 관리자에게도 기존 값이 보이게 됩니다. 옛 “필수” 조직의 설정이 “실명으로 표시” 켬으로 이전되는 처리와 함께 목적·제공 범위 변경의 고지 및 근거를 검토해야 합니다. 충돌 후보의 본인 선택·직접 입력, 실명 저장 시 후보 삭제, 되돌리기용 옛 실명 열의 실제 보유·접근·삭제 시점이 공개본의 계정 실명 통합 및 보유 고지와 일치하는지 확인해야 합니다. 근거: 계획 §2.1·§2.3·§13, privacy.md 제2조·제3조.
- **정정·탈퇴 및 이미 생성된 기록:** 실명 정정의 영향 범위와 조직 표시 이름의 본인·관리자 변경 및 Discord 명령 권한을 확인해야 합니다. 탈퇴 시 계정 실명·충돌 후보·조직 표시 이름 및 옛 실명 저장분이 실제 삭제되는지, 업무 본문·저장 당시 이력 문자열·전사문·외부 메시지·백업에는 이름이 남을 수 있다는 구분과 삭제 요청 절차의 적합성을 확인해야 합니다. 근거: 계획 §4.1·§4.3·§6.5, privacy.md 제3조·제7조·제8조·제9조, terms.md 제12조.
- **배포·재동의·화면 고지:** 확정 구조는 다음 로그인 시 시행 판 동의를 기록하는 기존 절차이며 별도 동의 화면을 새로 만들지 않습니다. 이 절차가 위 각 처리의 법정 요건을 충족하는지는 별도 판단이 필요합니다. 배포일 확정 후 약관 제3조의 사전 게시·중요 변경 통지 기간, 기존 연결의 30일 유예 문구가 이번 시행일로 다시 계산되는지 여부, 가입·초대 수락 시 관리자 열람 안내와 설정 변경 시 실명 공개 안내를 확인해야 합니다. HTML·DOC_VERSIONS(privacy v5·terms v4) 및 UI 문구는 이번 편집 범위 밖으로 구현 담당자가 반영·검증해야 합니다. 근거: 계획 §10의 3·7·8 및 §13의 10, privacy.md 제6조·제16조, terms.md 제3조.
