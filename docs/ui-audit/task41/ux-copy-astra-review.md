# 실제 화면 UX 문구 검토 — Astra

## 결론

- 검토 기준: 사용자에게 다음 행동, 적용 범위, 저장 방식, 설정 효과가 정확히 전달되는지. 취향에 가까운 단어 교체는 P3로 분리했다.
- 오늘과 태스크 상세는 Chrome에서 직접 읽었다. 나머지 탭은 부모가 실제 Docker 앱에서 수집한 `copy-screen-*.txt` 접근성 트리와 앞서 직접 본 동일 앱 캡처를 읽었다. 코드 분석이나 데이터 변경은 하지 않았다.
- 아래 수정안은 문구 제안이다. 실제 권한·저장·집계·의존 방향은 부모의 구현 대조 결과에 맞춰 확정해야 한다.

## P3 — 뜻을 유지하는 표현·일관성 개선

- 오늘 목록: `오늘 제외` → `오늘 목록에서 빼기`, `7일 완료` → `최근 7일 완료`, 마감 자동 담기는 `마감일 기준 자동 추가`로 설명한다. 새 기능을 암시하지 않는다. 출처: [오늘](http://127.0.0.1:8017/today), 직접 확인.
- 오늘 집중 태스크의 완료 버튼은 `태스크 완료로 표시`로 대상을 밝혀, 크게 보이는 다음 행동 한 항목만 완료하는 것으로 오해하지 않게 한다. 출처: [오늘](http://127.0.0.1:8017/today), 직접 확인.
- 목표일·기한·마감이 같은 날짜라면 대표 용어를 통일한다. 동작 의미가 다르면 유지해야 한다. 출처: [오늘](http://127.0.0.1:8017/today), [태스크](http://127.0.0.1:8017/tasks/2), [프로젝트 설정](http://127.0.0.1:8017/projects/1/settings).
- 막힘 에스컬레이션은 `막힘 관리자 알림`, 검토 독촉은 `검토 대기 알림`처럼 수신자와 목적 중심으로 바꿀 수 있다. 출처: [조직 설정](http://127.0.0.1:8017/orgs/1/settings), expanded AX.
- 저장 버튼은 여러 항목이 공존하는 팀 화면에서 `스킬 태그 저장`, 제거는 `조직에서 제외`처럼 범위를 밝혀도 좋다. 기존 확인 흐름의 의미를 먼저 확인한다. 출처: [팀](http://127.0.0.1:8017/orgs/1/teams), copy-screen-orgs-1-teams.txt.

## 확인한 화면과 확인 불가

- 실제 문구 확인: 오늘·태스크 상세, 내 태스크·프로젝트 상세/보드·조직 개요(기존 실제 캡처), 부하·로드맵·팀·거버넌스·조직 설정 5개 섹션·프로젝트 설정 3개 섹션·문서 본문/쓰는 법·회의록 본문·프로필·환경설정·API 토큰·API 문서 빈 상태·포트폴리오 빈 상태·검색 초기 화면.
- 조직 Discord/GitHub, 프로젝트 저장소/이슈 URL은 제공된 실제 AX에서 404였다. 해당 기능의 정상 화면 문구는 확인 불가다. 연결을 시도하거나 다른 원인을 추정하지 않았다.
- 토큰 발급 결과·폐기, 저장 성공/실패, 삭제/보관 최종 확인, 외부 연결 성공/실패, API 업로드 결과 등 변경 후 상태는 실행하지 않아 확인 불가다.
- 브라우저 자동화가 확장 UI 때문에 중단된 뒤에는 부모가 제공한 실제 AX 자료로 검토했다. 소스 오류 메시지는 다른 검토 갈래의 담당이다.
