근거
- 두 HTML 모두 기존 app.css와 ../../core/web/static/vendor/tiptap.bundle.js를 직접 참조하는 독립 시안이다.
- 각 시안에 편집기 15개(태스크 3, 결정 4, 사유 3, 요청 1, 거버넌스 2, 포트폴리오 1, 문서 1)와 읽기 전용 렌더 3개를 제공한다.
- 1440px·390px Chromium에서 직접 입력했으며 한글 텍스트, Ctrl+B/K, 읽기 화면 동기화, 필수 사유 오류, 모달 제출을 검증했다.
- 두 안 모두 마크다운 제목·목록·체크·코드 입력 규칙, URL 붙여넣기, 말풍선 클릭·키보드 조작을 검증했다.
- 스크린샷을 직접 열어 시각 확인했고 페이지 가로 넘침·자바스크립트 오류는 없었다.
- 상세 결과: astra-check-results.json, astra-interaction-results.json.

불일치·누락
- 저장·제출은 시안의 현재 메모리, 숨긴 마크다운 필드, 읽기 전용 화면만 갱신한다. 새로고침하면 초기화된다.
- 공통 브리프에 맞춰 멈춤 사유도 필수로 표시했다. 실제 tasks/_stop.html의 일반 멈춤 사유는 선택 사항이므로 적용 시 기존 정책과 정합성을 결정해야 한다.
- 앱 코드·템플릿·DB는 수정하지 않았다. 작성한 파일은 지정 시안 폴더에만 있다.

확인 불가
- 실제 OS 한국어 IME 조합과 실제 모바일 가상 키보드는 자동화로 확인하지 못했다. 한글 텍스트 입력 및 합성 composition 이벤트 동안 자동 반영을 보류하는 동작만 확인했다.
- 서버 저장·HTMX 재초기화·동시 수정 충돌은 앱 통합 범위이므로 이 시안에서 검증하지 않았다.
